Frequently Asked Questions

Common questions about AuditAI and how to use it.

How does AuditAI differ from Slither alone?

Slither is one of our detection engines. AuditAI adds Aderyn cross-validation, LLM enrichment via RAG knowledge, automated PoC generation, and on-chain attestation. Think of it as Slither++ with verification.

What chains does AuditAI support?

AuditAI analyzes EVM-compatible Solidity code. Attestation currently targets Sepolia testnet, with mainnet support planned. Any EVM chain (Ethereum, Polygon, Arbitrum, Base, etc.) works for analysis.

Is the knowledge base available offline?

Yes. The 477 Solodit reports and 303 vulnerability references are bundled as ChromaDB vectors. First run indexes them locally; subsequent runs use the cached index.

Can I integrate AuditAI into my CI/CD pipeline?

Absolutely. AuditAI has a CLI that exits with non-zero code on findings. Use it in GitHub Actions, GitLab CI, or any pipeline. The MCP server also enables IDE integration.

Is AuditAI free to use?

Yes! AuditAI is open source under the MIT license. Free for personal and commercial use. No per-seat licensing or hidden fees.
