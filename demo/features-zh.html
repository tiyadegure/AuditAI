常见漏洞

AuditAI 检测的典型漏洞类型。点击标签查看详细信息。

高危 withdraw() 重入漏洞

withdraw() 函数在更新余额前发送 ETH，违反了 CEI（检查-效果-交互）模式。攻击者可通过 fallback 函数重入以耗尽合约资金。由 Slither (reentrancy-eth) 检测，并由 Foundry 模糊测试确认。修复方案：先更新状态，再进行外部调用。

中危 余额计算整数溢出

Solidity 0.8 之前的余额累加算术可能在大额存款时溢出。虽然 SafeMath 在新版本中缓解了此问题，但遗留合约仍然脆弱。由 Slither 检测并经目标模糊输入验证。

高危 缺少访问控制

setOwner() 函数缺少任何修饰符，允许任何人获取合约所有权。与重入漏洞组合可创建关键攻击链。由 Aderyn 检测并通过 LLM 与 477 份审计报告的 RAG 知识交叉验证。

中危 预言机价格操控

DEX 储备的现货价格可在单笔交易内通过闪电互换操控。建议使用 TWAP 预言机（Chainlink、Uniswap V3 TWAP）。模式从 Solodit 知识库以 0.89 相似度匹配。

高危 闪电贷攻击向量

deposit() 接受任意代币数量而不验证调用者实际余额。闪电贷可膨胀合约感知的 TVL。建议：使用 permit + transferFrom 并进行余额检查。通过 RAG 检索匹配 EVMbench 模式发现。

中危 抢跑攻击（Front-Running）

交易排序依赖（TOD）和 MEV 漏洞。公开的 mempool 允许矿工/验证者或搜索者通过重排交易获利。建议使用提交-揭示方案或私有交易池。
